# Basic Programming Lab

This repository contains the **Basic Programming Lab** projects for the Computer Engineering Department at **Amirkabir University of Technology (AUT)**. The lab exercises focus on the fundamentals of **C programming**, helping students develop problem-solving skills and a deep understanding of basic programming concepts.

---

## Project Description
The projects in this repository cover the basic concepts of **C programming** such as variables, loops, functions, arrays, pointers, and file I/O. Students will implement various algorithms, data structures, and solve computational problems as part of the coursework.

### Key Concepts
- **Variables & Data Types**: Using basic data types such as `int`, `float`, `char`, and `double`.
- **Control Structures**: Implementing conditional statements (`if`, `else`, `switch`) and loops (`for`, `while`, `do-while`).
- **Functions**: Defining and calling functions, understanding the scope and lifetime of variables.
- **Arrays**: Working with arrays to store and manipulate collections of data.
- **Pointers**: Using pointers for dynamic memory allocation and manipulation.
- **File I/O**: Reading from and writing to files for persistent data storage.
- **Basic Algorithms**: Implementing algorithms like sorting and searching (e.g., bubble sort, linear search).
- **Basic Data Structures**: Using simple structures like arrays and structs to manage data.

## How to Compile and Run

### Prerequisites:
- **C Compiler**: Install a C compiler like **GCC** to compile the C code.
- **Operating System**: The program can be run on Linux, Windows, or macOS.

### Steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/yarahmadi0077/Basic-Programming-Lab.git
   cd Basic-Programming-Lab
   ```

2. Compile the C program:
   If you're using **GCC** as the compiler:
   ```bash
   gcc -o program_name program_name.c
   ```

3. Run the compiled program:
   ```bash
   ./program_name
   ```

## Key Concepts and Implementation

### 1. **Variables and Data Types**
   - Understand and use the basic data types in C, such as `int`, `float`, `char`, and `double`, to store and manipulate different kinds of data.

### 2. **Control Structures**
   - Learn how to use conditional statements like `if`, `else`, and `switch` to implement decision-making logic.
   - Implement loops (`for`, `while`, `do-while`) for repeating tasks.

### 3. **Functions**
   - Break down problems into smaller, reusable functions. Learn how to define, call, and pass parameters to functions.

### 4. **Arrays and Strings**
   - Store and manipulate collections of data using arrays. Also, work with strings as arrays of characters.

### 5. **Pointers**
   - Learn how to use pointers for indirect memory access and dynamic memory allocation.

### 6. **File I/O**
   - Read and write to files, helping store data persistently.

### 7. **Basic Algorithms**
   - Implement sorting algorithms like **Bubble Sort**, and searching algorithms like **Linear Search**.

### 8. **Basic Data Structures**
   - Use arrays and structures (`struct`) to store and organize related data.
